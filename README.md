## Usage

1. Place `dangbox.sty` in the same folder as your LaTeX file.  
2. Include it in your document:

```latex
\usepackage{dangbox}
\begin{dang}[title=Example]
\begin{itemize}
  \item Item 1
  \item Item 2
\end{itemize}
\end{dang}
